# 5 分钟上手 AIcoding

## 你需要的

- 一台电脑
- 一个 AI 编程工具：Cursor / Claude Code / Codex（任一）
- 本仓库的 `skill/` 目录

## 三步开始

### 第 1 步：安装 Skill（1 分钟）

```bash
# Cursor
cp -r skill/* ~/.cursor/skills/aicoding/

# Claude Code
mkdir -p ~/.claude/skills/aicoding/
cp skill/SKILL.md skill/reference.md ~/.claude/skills/aicoding/

# Codex
cp skill/SKILL.md ~/.codex/skills/aicoding.md
```

### 第 2 步：说需求（30 秒）

打开你的 AI 工具，说一句话：

```
帮我做一个完整的项目：[你的需求描述]
```

**需求写得好，交付就靠谱。** 包含四个要素：

| 要素 | 例子 |
|------|------|
| 是什么 | "机器人远程监控面板" |
| 技术栈（可选） | "FastAPI + Vue3" |
| 关键功能 | "多设备接入、实时数据推送" |
| 交付要求（可选） | "带 Docker 部署" |

### 第 3 步：验收（3 分钟）

交付后，一条命令验证：

```bash
git clone <交付的仓库>
cd <项目>
docker compose up
# 打开 http://localhost:8000 看到界面 = 成功
```

## 进阶用法

### 指定架构

```
"用事件驱动架构 + PostgreSQL + Redis 缓存，前后端分离"
```

### 限定范围

```
"先只做 MVP：登录 + 核心页面，其他功能后续迭代"
```

### 要求技术细节

```
"后端要 80% 测试覆盖率，前端要有响应式设计，都要过 ESLint"
```

## 常见问题

| 问题 | 解法 |
|------|------|
| 交付的项目跑不起来 | 把报错贴给 AI，它会修 |
| 技术栈不是想要的 | 需求里写清楚技术栈 |
| 想改一个功能 | "把 X 改成 Y，保留 Z" |
| 交付太大 | "先交付 MVP" |
